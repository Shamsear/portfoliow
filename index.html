How I ship with AI

AI tools make me fast. Types, tests and review make the result safe to ship. I use the speed and I keep the checks.

  • Cursor
  • Claude Code
  • GitHub Copilot
  1. Types

    Catch errors before the code runs

    Strict TypeScript interfaces, Zod validation and PostgreSQL schemas define what data is allowed. Generated code has to fit those contracts or it does not compile.

  2. Tests

    Prove the edge cases

    Unit and integration tests with Jest or Vitest cover state boundaries, API error responses and the inputs nobody expects.

  3. Review

    Read every line before it merges

    I review AI output line by line for security, clear architecture and code a teammate can maintain. If I cannot explain a line, it does not ship.
